# Academy City: concept folder

Everything we plan before building lives here. The game itself lives in `Assets/AcademyCity`; Unity never reads this folder.

| Folder | What goes in it |
|---|---|
| [story/](story/) | The world, the rules of the city, the characters and the plot. Only locked decisions go in, marked with the date David agreed them. |
| [script/](script/) | Written scenes: who says what, in order, with the player's choices. |
| [storyboard/](storyboard/) | Scene by scene sketches: what the camera sees, framing and timing for cutscenes and key moments. |
| [assets/](assets/) | Concept art and references for characters, locations and UI. Approved art is marked as approved; everything else is a draft. |

## How we work
1. Decide it together. Nothing is added that David hasn't agreed to.
2. Write it down here (story, then script, then storyboard).
3. Draw concepts in `assets/`. David picks; picks are marked approved.
4. Only then build it in the game.
