# Art style

Not locked yet. The style chosen here sets the look of the whole game, including in-game models. It also depends on whether the game is 3D or 2D (still to decide).

## board-1nov
Hanson drawn in four styles, two takes each (`styleboard.png`):
- **A Bold ink:** thick outlines, hard shadows, warm rim light (Hades feel).
- **B Bright anime:** clean lines, flat cel shading, bright colours (Genshin feel; easiest to match in 3D).
- **C Soft painterly:** watercolour, warm and cosy (Ghibli feel).
- **D Dark manhwa:** dramatic lighting, night, glowing effects.
