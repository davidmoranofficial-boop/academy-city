## How we work
1. David describes the idea (voice note is fine).
2. Claude reads the topic note, researches anything missing, and adds to it.
3. Build, then run the auto checks (06) on a sim fight.
4. Make a frame sheet: our key frames next to the key poses listed here.
5. Only clips that pass go to David, with an honest critique. Never call animation "good"; David judges.
